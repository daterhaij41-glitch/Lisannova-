# LisanNova — مشروع أندرويد جديد مستقل

هذه قاعدة مشروع جديدة باسم **LisanNova**، مستقلة بالكامل ولا تنقل ملفات أو أكواد من أي مشروع سابق.

## ما الموجود فعليًا في هذه النسخة

- واجهة Android جديدة لاختيار فيديو واختيار ملف Whisper بصيغة GGML.
- نسخ الفيديو والنموذج إلى مساحة التطبيق الخاصة حتى لا يعتمد المعالج على صلاحيات مسارات خارجية.
- استخراج الصوت من الفيديو إلى PCM أحادي القناة بتردد 16 kHz باستخدام FFmpeg.
- ربط Whisper.cpp عبر JNI/CMake، مع تثبيت لغة التعرف على التركية.
- تقسيم الصوت إلى مقاطع 30 ثانية مع تداخل 4 ثوانٍ، وتشغيل النموذج مرة واحدة لكل الحلقة بدل إعادة تحميله لكل مقطع. تُحفظ الجمل القريبة من حدود المقاطع، مع إزالة التكرار النصي المتطابق القريب زمنيًا.
- حفظ النص التركي الناتج في ملف SRT.
- عند إعداد خدمة ترجمة متوافقة مع OpenAI Chat Completions، يرسل التطبيق **نص الجمل فقط** على دفعات مع تعليمات ترجمة سياقية إلى العربية، ثم يكتب SRT عربيًا.
- بعد نجاح الترجمة، يستخدم FFmpeg لحرق الترجمة العربية داخل الفيديو وإنتاج MP4 جديد في `Movies/LisanNova`.
- الفيديو الأصلي لا يتغير.
- GitHub Actions لبناء APK ورفعه كـ Artifact.

## حدّ مهم يجب معرفته

هذا الإصدار الأول **ليس تطبيقًا نهائيًا مثبت الجودة بعد**، وهو لا يحقق بعد شرط الترجمة العربية الكاملة دون اتصال. التعرف على الكلام محلي. أما الترجمة العربية في هذه النسخة فتحتاج عنوان خدمة ترجمة متوافقًا ومفتاحها واسم النموذج. لا توجد ترجمة محلية تركية→عربية عالية الجودة مدمجة في هذا الإصدار؛ لم أضع ML Kit كحل افتراضي لأن توثيق Google يذكر أن الترجمة بين لغتين غير الإنجليزية تمر عبر الإنجليزية، وهذا قد يغيّر المعنى. كما لم أضع NLLB-200 كخيار افتراضي: حجمه ومتطلباته وترخيصه غير مناسبة كخيار بسيط على هاتف منخفض القدرة.

لا يتم إرسال الفيديو أو الصوت إلى خدمة الترجمة. عند تفعيلها، يرسل التطبيق نصوص الجمل التركية فقط. راجع سياسة مزود الخدمة الذي تختاره قبل إدخال مفتاحه. مفتاح الخدمة يُشفّر باستخدام Android Keystore قبل حفظه في SharedPreferences. لا تشارك مفتاحك مع أي شخص، واختر مزود ترجمة موثوقًا.

## توافق الجهاز والأداء

الهدف الأولي هو `arm64-v8a`، مع `minSdk 26` و`targetSdk 35`. لا أضمن سرعة معالجة حلقة ساعتين على هاتف Infinix Hot 30i؛ النموذج الكبير قد يكون بطيئًا أو يستهلك ذاكرة كثيرة. ابدأ بمقطع قصير من 2–3 دقائق، وقارن نتيجة التعرف على الكلام قبل اختبار حلقة كاملة.

## الملف النموذجي

يمكن اختيار ملف GGML من مدير الملفات. إذا كان لديك الملف:

`ggml-whisper-large-v3-turkish-general-q5_0.bin`

فلا يلزم تنزيله مجددًا قبل تجربة توافقه. يجب أن يكون ملف GGML متوافقًا مع Whisper.cpp؛ مجرد امتداد `.bin` لا يكفي وحده لإثبات التوافق.

## البناء عبر GitHub Actions

1. أنشئ مستودع GitHub جديدًا فارغًا باسم `LisanNova`.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بما فيها المجلد المخفي `.github/workflows`.
3. افتح تبويب Actions وشغّل `Build LisanNova APK` من زر `Run workflow`.
4. لا تعتبر البناء ناجحًا إلا إذا اكتمل الـ workflow باللون الأخضر وظهر Artifact باسم `LisanNova-debug-apk`.

البناء يجلب Whisper.cpp أثناء CMake من مستودعه الرسمي؛ لذلك يحتاج اتصال إنترنت أثناء عملية البناء.

## حدود الاختبار الحالية

لم يُنفذ بناء Android فعلي داخل بيئة إعداد الملفات هذه، ولم يُختبر APK على هاتف حقيقي بعد. هذا الملف هو مصدر المشروع الأولي مع سير العمل المقترح، وليس APK مُثبت النجاح. عند أول بناء، يجب إصلاح أي خطأ يظهر من سجل GitHub Actions بدل تغيير ملفات عشوائيًا.
